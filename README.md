# Palika Live — Navigation Prototype (पालिका लाइभ नेभिगेसन प्रोटोटाइप)

palikalive.com को मुख्य मेनु/नेभिगेसन पुनर्संरचनाको अन्तरक्रियात्मक HTML मकअप।

## कसरी हेर्ने
- `index.html` ब्राउजरमा खोल्नुहोस् (वा लाइभ प्रिभ्यूबाट)।
- माथिको डेमो बारबाट **३ वटा मेनु मोडल** र **डेस्कटप/मोबाइल भ्यू** स्विच गर्न सकिन्छ।

## मेनु मोडलहरू
1. **हाइब्रिड (सिफारिस)** — `ताजा · पालिका ▾ · प्रदेश ▾ · सुशासन वाच · अर्थ पालिका · राजनीति · समाज · बहस ▾ · भिडियो`
2. **स्वच्छ न्युज** — हालकै संरचनाको सुधारिएको ९-आइटम संस्करण
3. **दर्शक-आधारित** — `नागरिक · जनप्रतिनिधि · कर्मचारी · सुशासन वाच · बजेट/डाटा · राजनीति · समाचार`

## मुख्य फिचरहरू
- **पालिका ▾ मेगा-मेनु**: autocomplete सहितको ७५३-पालिका सर्च (डेमोमा नमुना डाटा), प्रोफाइल/डाटा-हब लिङ्क, चर्चित पालिका कार्ड
- **प्रदेश ▾**: ७ प्रदेश + संघ/सिंहदरबार
- **मोबाइल ड्रअर**: ह्यामबर्गर मेनु + accordion सब-मेनु + सर्च
- पृष्ठको तल **WordPress म्यापिङ तालिका** (पुराना URL यथावत् राख्ने नियम) र ३-चरण कार्यान्वयन योजना

## फाइलहरू
- `index.html` — सम्पूर्ण प्रोटोटाइप (HTML + CSS + JS एकै फाइलमा, कुनै बिल्ड आवश्यक छैन)
- `assets/` — डेमोका लागि प्लेसहोल्डर तस्बिरहरू (वास्तविक साइटका होइनन्)

## नोट
शीर्षकहरू palikalive.com का वास्तविक हुन्; तस्बिरहरू डेमो-मात्र प्लेसहोल्डर हुन्।
